Установка окружения

Прежде чем писать мод, нужно подготовить инструменты. Это займёт минут 20-30. После этого шага у тебя будет всё, чтобы создавать моды на Fabric для Minecraft 1.21.

Мы будем использовать Fabric — это современный загрузчик модов для Minecraft. Он проще и быстрее, чем Forge, и на нём работает большинство визуалов и оптимизационных модов.

1. Java 21

Моды пишутся на Java. Minecraft 1.21 требует Java 21. Если у тебя установлена другая версия — скорее всего проект не соберётся.

Проверь, что у тебя уже есть

Открой терминал (Win + R → cmd → Enter) и введи:

bash 
java --version

Если увидишь что-то вроде java 21.0.10 — всё отлично, переходи к следующему шагу.

Если пишет «java не является внутренней командой» — Java не установлена или не добавлена в PATH. Тогда устанавливай.

Установка JDK 21

Качай Eclipse Temurin JDK 21 — это бесплатная сборка OpenJDK от Adoptium. Она стандартная для Minecraft-разработки.

  • Открой adoptium.net
  • Выбери Operating System: Windows, Architecture: x64, Version: 21 — LTS
  • Скачай .msi installer
  • Запусти установщик. В окне «Custom Setup» включи «Add to PATH» и «Set JAVA_HOME variable»
  • Жми Next до конца, установи

После установки закрой и открой терминал заново (важно — старый терминал не подхватит изменения PATH). И снова проверь:

bash 
java --version

Должно показать openjdk 21.x.x.

2. IntelliJ IDEA

Это среда разработки. В ней ты будешь писать код, собирать и запускать мод. Нужна Community Edition — она бесплатная.

  • Открой jetbrains.com/idea/download
  • Пролистай до Community Edition (не Ultimate)
  • Скачай, установи
  • При первом запуске пропусти настройки, оставь всё по умолчанию
Альтернатива — VS Code с расширениями для Java. Но для Fabric-модов IntelliJ удобнее: он сам подтягивает Gradle и понимает структуру проекта.

3. Fabric Mod Template

Это готовый каркас проекта. Не нужно создавать всё с нуля — генерируешь шаблон и сразу начинаешь писать код.

  • Открой fabricmc.net/develop/template
  • Заполни поля:
    • Mod Name: MyFirstMod (любое, но латиницей, без пробелов)
    • Package Name: com.example.myfirstmod (латиница, точка как разделитель)
    • Minecraft Version: 1.21.4 (или другая, под которую делаешь мод)
    • Mod ID: myfirstmod (латиница, строчные)
    • Остальное оставь по умолчанию
  • Нажми Download Template

Скачается ZIP-архив. Распакуй его в папку без пробелов и русских букв в пути. Например:

путь 
C:\Projects\MyFirstMod
Не размещай проект на рабочем столе или в папках типа «Загрузки». Если в пути есть пробелы или кириллица, Gradle может не собрать проект.

4. Открыть проект в IDEA

  • Запусти IntelliJ IDEA
  • File → Open
  • Выбери папку MyFirstMod (именно папку, не файл внутри)
  • Нажми OK
  • IDEA спросит «Trust Project?» — жми Trust Project

Начнётся импорт Gradle — он подтянет зависимости и исходники Minecraft. Это займёт 5-15 минут в первый раз. Внизу будет прогресс-бар, не закрывай IDEA.

5. Проверка SDK

Когда импорт закончится, проверь что используется правильная Java:

  • File → Project Structure (или Ctrl + Alt + Shift + S)
  • Слева Project
  • В поле SDK должно стоять 21 (например, temurin-21 или openjdk-21)
  • Если стоит другая версия — нажми на выпадающий список, выбери Add SDK → Download JDK, версия 21, vendor любой
  • Apply → OK

6. Первый запуск

Убедимся что всё работает. В правом верхнем углу IntelliJ должна быть выпадашка с названием Minecraft Client и зелёный треугольник рядом.

  • Нажми на зелёный треугольник Run
  • Gradle соберёт мод и запустит Minecraft
  • Первый запуск долгий (2-5 минут), потому что скачиваются все ассеты игры
  • Откроется окно Minecraft. Ты в игре — пока без твоего мода, но с рабочей средой
Если Minecraft запустился — окружение готово. Можно переходить к следующему гайду и писать код.

Если что-то пошло не так

Gradle sync failed

Чаще всего это проблема с версией Java. Проверь пункт 5 (SDK 21). Если не помогло — открой вкладку Build внизу IDEA, скопируй текст ошибки.

Could not set unknown property 'sourceCompatibility'

Проект написан под старую версию Gradle, а IDEA использует новую. Решение: в панели Gradle (справа) → шестерёнка → Gradle Settings → Distribution поставь Local installation → выбери Gradle 8.10 или ниже.

java --version показывает не 21

Значит, PATH не обновился. Закрой терминал, открой заново. Если не помогло — перезагрузи компьютер. Windows иногда не подхватывает изменения PATH сразу.
