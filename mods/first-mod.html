Первый мод

Разбираем структуру Fabric-проекта и пишем первый рабочий мод. К концу гайда у тебя будет мод, который выводит сообщение в чат при запуске игры.

Прежде чем лезть в рендер и Mixin — нужно понять, как вообще устроен мод. Мы напишем простой мод, который делает одну вещь: при запуске Minecraft пишет в чат «Мод загружен». Просто, но это рабочий каркас, на который дальше навешивается всё остальное.

1. Структура проекта

Открой папку своего проекта в IntelliJ. Ты увидишь такую структуру:

структура 
MyFirstMod/
├── src/
│   └── main/
│       ├── java/
│       │   └── com/example/myfirstmod/
│       │       └── MyFirstMod.java      ← главный класс мода
│       └── resources/
│           ├── fabric.mod.json          ← описание мода
│           └── myfirstmod.mixins.json   ← конфиг миксинов (пустой)
├── build.gradle                          ← настройки сборки
└── gradle.properties                     ← версии и параметры

Самое важное — MyFirstMod.java. Это точка входа, с неё Minecraft начинает загрузку твоего мода.

2. Главный класс

Открой MyFirstMod.java. Ты увидишь примерно такой код:

java 
package com.example.myfirstmod;

import net.fabricmc.api.ModInitializer;

public class MyFirstMod implements ModInitializer {
    public static final String MOD_ID = "myfirstmod";

    @Override
    public void onInitialize() {
        // Здесь код, который выполняется при загрузке мода
    }
}

Разберём что тут что:

  • package com.example.myfirstmod; — пакет, определяет где лежат твои классы
  • implements ModInitializer — говорит Fabric, что это точка входа мода
  • MOD_ID — уникальный идентификатор мода (тот, что ты указывал в шаблоне)
  • onInitialize() — метод, который Fabric вызывает один раз при запуске игры

Всё, что ты напишешь в onInitialize(), выполнится при загрузке мода. Это идеальное место чтобы зарегистрировать блоки, предметы, события.

3. Добавляем лог

Вместо того чтобы сразу писать в чат (это чуть сложнее), начнём с лога. Это стандартный способ проверить что мод загрузился.

Добавь логгер и напиши в него сообщение:

java 
package com.example.myfirstmod;

import net.fabricmc.api.ModInitializer;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class MyFirstMod implements ModInitializer {
    public static final String MOD_ID = "myfirstmod";
    public static final Logger LOGGER = LoggerFactory.getLogger(MOD_ID);

    @Override
    public void onInitialize() {
        LOGGER.info("Мод MyFirstMod загружен!");
    }
}

LOGGER.info() — метод, который выводит сообщение в консоль. Не в чат игры, а в лог — то что видно в терминале, откуда ты запускал Minecraft.

4. Запускаем и проверяем

  • В правом верхнем углу IntelliJ выбери конфигурацию Minecraft Client
  • Нажми зелёный треугольник Run
  • Дождись запуска Minecraft
  • Посмотри в нижнюю панель IntelliJ — там будет лог запуска

Найди в логе строку:

лог 
[main/INFO]: Мод MyFirstMod загружен!
Если видишь эту строку — твой первый мод работает. Поздравляю.

5. Пишем в чат игры

Лог — это хорошо, но интереснее вывести сообщение прямо в игре. Правда, есть нюанс: в момент загрузки мода игрок ещё не зашёл в мир. Поэтому сообщение в чат пишут после входа в мир — через событие.

Fabric предоставляет ClientPlayConnectionEvents.JOIN — событие, которое срабатывает когда игрок подключается к серверу или заходит в мир.

java 
package com.example.myfirstmod;

import net.fabricmc.api.ClientModInitializer;
import net.fabricmc.fabric.api.client.networking.v1.ClientPlayConnectionEvents;
import net.minecraft.text.Text;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class MyFirstMod implements ClientModInitializer {
    public static final String MOD_ID = "myfirstmod";
    public static final Logger LOGGER = LoggerFactory.getLogger(MOD_ID);

    @Override
    public void onInitializeClient() {
        ClientPlayConnectionEvents.JOIN.register((handler, sender, client) -> {
            if (client.player != null) {
                client.player.sendMessage(Text.literal("§aМод MyFirstMod загружен!"), false);
            }
        });
    }
}

Разберём что изменилось:

  • ModInitializer → ClientModInitializer — мод только клиентский, не для сервера
  • onInitialize() → onInitializeClient() — метод для клиентской инициализации
  • ClientPlayConnectionEvents.JOIN — событие входа в мир
  • Text.literal("§a...") — текст, где §a это цветовой код (зелёный)
  • sendMessage(..., false) — отправить сообщение, false значит «не в actionbar»
Про цвета в Minecraft — символ § (параграф) задаёт цвет текста. §a — зелёный, §c — красный, §e — жёлтый, §b — голубой. Полный список есть в вики Minecraft.

6. Проверяем

Запусти игру заново (Run). Зайди в любой мир. В чате должно появиться зелёное сообщение «Мод MyFirstMod загружен!».

Если сообщение появилось — ты освоил базу. Теперь можно переходить к Mixin — это то, через что делаются все крутые моды, включая TargetHUD.

Что дальше

Сейчас мод делает только одно. Но у тебя есть каркас:

  • Точка входа — ClientModInitializer
  • События — ClientPlayConnectionEvents
  • Логирование — LOGGER
  • Работа с текстом — Text.literal

Дальше можно вешать любые события: нажатие клавиш, каждый тик игры, отрисовку HUD. Это всё — через fabric-api, который уже подключён в проекте.
