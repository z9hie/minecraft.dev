TargetHUD

Собираем всё вместе: находим цель под прицелом, вытаскиваем данные о ней и рисуем панель на экране. Тот самый мод, который показывает HP, ник и расстояние до противника.

TargetHUD — это классика PvP-модов. Когда ты наводишь прицел на игрока, в углу экрана появляется панель с его ником, здоровьем, бронёй, предметом во второй руке и расстоянием до него. Разберём как это делается по шагам.

1. План

Мод делает три вещи:

  1. Определяет цель — кто под прицелом прямо сейчас
  2. Собирает данные — HP, ник, второй предмет, расстояние
  3. Рисует панель — в углу экрана, каждый кадр

У нас будет два класса: TargetHudRenderer для отрисовки и TargetHudClient для инициализации. Плюс миксин, чтобы вклиниться в момент отрисовки HUD Minecraft.

2. Определяем цель

У Minecraft есть встроенная система «на что смотрит игрок» — crosshairTarget. Она возвращает то, на что наведён прицел: блок, сущность или воздух.

java 
import net.minecraft.client.MinecraftClient;
import net.minecraft.entity.Entity;
import net.minecraft.entity.player.PlayerEntity;
import net.minecraft.util.hit.EntityHitResult;
import net.minecraft.util.hit.HitResult;

public class TargetHudRenderer {

    public static PlayerEntity getTargetPlayer() {
        MinecraftClient client = MinecraftClient.getInstance();
        if (client.crosshairTarget == null) return null;
        if (client.crosshairTarget.getType() != HitResult.Type.ENTITY) return null;

        Entity entity = ((EntityHitResult) client.crosshairTarget).getEntity();
        if (!(entity instanceof PlayerEntity)) return null;
        if (entity == client.player) return null;

        return (PlayerEntity) entity;
    }
}

Что тут происходит:

  • MinecraftClient.getInstance() — получаем текущий клиент игры
  • client.crosshairTarget — то, на что смотрит прицел
  • Проверяем тип HitResult.Type.ENTITY — значит наведён на сущность
  • Приводим к EntityHitResult и получаем саму сущность
  • Проверяем что это PlayerEntity и что это не сам игрок
Важный нюанс. crosshairTarget работает только на ванильной дальности — примерно 4.5 блока. Если хочешь видеть цель на 30 блоках (как ты просил другу), нужно делать свой raycast. Про это в конце гайда.

3. Собираем данные

Теперь когда у нас есть PlayerEntity, вытаскиваем всё что нужно:

java 
PlayerEntity target = getTargetPlayer();
if (target == null) return;

// Ник
String name = target.getName().getString();

// Здоровье
float health = target.getHealth();
float maxHealth = target.getMaxHealth();
float healthPercent = health / maxHealth;

// Броня
int armor = target.getArmor();

// Предмет во второй руке
ItemStack offHand = target.getOffHandStack();
boolean hasOffHand = !offHand.isEmpty();

// Расстояние
double distance = MinecraftClient.getInstance().player.distanceTo(target);

Все эти методы есть в PlayerEntity и LivingEntity — родительском классе. Ты можешь смотреть их в исходниках Minecraft через genSources.

4. Рисуем панель

Отрисовка — самая объёмная часть. Для неё используется DrawContext — класс, который предоставляет методы рисования: fill(), drawText(), drawItem().

java 
import net.minecraft.client.gui.DrawContext;
import net.minecraft.client.MinecraftClient;

public static void render(DrawContext context) {
    PlayerEntity target = getTargetPlayer();
    if (target == null) return;

    MinecraftClient client = MinecraftClient.getInstance();
    int screenWidth = context.getScaledWindowWidth();

    // Размеры панели
    int panelWidth = 150;
    int panelHeight = 52;

    // Позиция — правый верхний угол с отступом
    int x = screenWidth - panelWidth - 12;
    int y = 12;

    // Фон панели (чёрный с прозрачностью)
    context.fill(x, y, x + panelWidth, y + panelHeight, 0xC0101010);

    // Ник
    context.drawText(
        client.textRenderer,
        target.getName().getString(),
        x + 8, y + 6,
        0xFFFFFFFF,
        true
    );

    // Полоска здоровья
    float health = target.getHealth();
    float maxHealth = target.getMaxHealth();
    float ratio = health / maxHealth;
    int barWidth = panelWidth - 16;
    int barX = x + 8;
    int barY = y + 22;

    // Фон полоски
    context.fill(barX, barY, barX + barWidth, barY + 4, 0xFF2A2A2A);
    // Заполнение (красный)
    context.fill(barX, barY, barX + (int)(barWidth * ratio), barY + 4, 0xFFFF5555);

    // HP числом
    String hp = String.format("%.1f / %.1f", health, maxHealth);
    context.drawText(client.textRenderer, hp, barX, barY + 8, 0xFFDDDDDD, true);

    // Расстояние
    double distance = client.player.distanceTo(target);
    String dist = String.format("%.1f м", distance);
    context.drawText(client.textRenderer, dist, x + panelWidth - 42, barY + 8, 0xFFAAAAAA, true);
}

Ключевые методы DrawContext:

  • fill(x1, y1, x2, y2, color) — залить прямоугольник цветом
  • drawText(renderer, text, x, y, color, shadow) — нарисовать текст
  • drawItem(stack, x, y) — нарисовать предмет

Цвета задаются в формате 0xAARRGGBB: альфа, красный, зелёный, синий. 0xC0101010 — это чёрный с прозрачностью 75%.

5. Как вызвать render

Метод render() сам себя не вызовет. Нужно вклиниться в момент, когда Minecraft рисует HUD. Тут нам помогает Mixin.

java 
package com.example.myfirstmod.mixin;

import com.example.myfirstmod.TargetHudRenderer;
import net.minecraft.client.gui.hud.InGameHud;
import net.minecraft.client.gui.DrawContext;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.injection.Inject;
import org.spongepowered.asm.mixin.injection.callback.CallbackInfo;
import org.spongepowered.asm.mixin.injection.At;

@Mixin(InGameHud.class)
public class InGameHudMixin {

    @Inject(method = "render", at = @At("TAIL"))
    private void onRenderHud(DrawContext context, float tickDelta, CallbackInfo ci) {
        TargetHudRenderer.render(context);
    }
}

Разбор:

  • @Mixin(InGameHud.class) — вклиниваемся в класс HUD игры
  • method = "render" — в метод отрисовки HUD
  • @At("TAIL") — в конец метода, после того как Minecraft нарисовал свой HUD
  • Параметры метода должны совпадать с оригиналом: DrawContext и float tickDelta

Теперь каждый кадр, после отрисовки ванильного HUD, вызывается наш TargetHudRenderer.render(). И поверх всего рисуется панель с информацией о цели.

Не забудь зарегистрировать миксин в myfirstmod.mixins.json — добавь "InGameHudMixin" в массив mixins. Без этого ничего не заработает.

6. Регистрация в главном классе

Осталось только сказать моду, что мы используем TargetHudRenderer. В главном классе:

java 
public class MyFirstMod implements ClientModInitializer {
    public static final String MOD_ID = "myfirstmod";

    @Override
    public void onInitializeClient() {
        LOGGER.info("TargetHUD загружен");
    }
}

Вся логика уже в миксине — он сам вызовет render. Главный класс нужен только для загрузки мода.

7. Тестируем

  • Запусти игру через Run
  • Зайди в мир, поставь рядом второго игрока (или моба — но у нас фильтр на PlayerEntity, так что нужен именно игрок)
  • Наведи прицел на игрока — в правом верхнем углу появится панель
  • Убери прицел — панель исчезнет
Если панель появилась — у тебя рабочий TargetHUD. Это уже полноценный мод, можно показывать другу.

8. Расстояние до 30 блоков

Сейчас панель показывает только того, кто в ванильной дальности прицела (~4.5 блока). Если хочешь видеть цель на 30 блоках — нужно делать свой raycast.

Идея такая:

  1. Берём позицию глаз игрока и направление взгляда
  2. Путем перебора всех игроков в радиусе 30 блоков находим тех, кто близок к лучу взгляда
  3. Из них выбираем самого близкого к центру прицела

Примерный код:

java 
public static PlayerEntity findPlayerInSight(double maxDistance) {
    MinecraftClient client = MinecraftClient.getInstance();
    if (client.player == null || client.world == null) return null;

    Vec3d eyes = client.player.getEyePos();
    Vec3d look = client.player.getRotationVec(1.0f);

    PlayerEntity best = null;
    double bestDot = 0.97; // порог "прицеливания"

    for (PlayerEntity player : client.world.getPlayers()) {
        if (player == client.player) continue;

        Vec3d toPlayer = player.getPos().add(0, player.getHeight() / 2.0, 0).subtract(eyes);
        double distance = toPlayer.length();
        if (distance > maxDistance) continue;

        Vec3d toPlayerNorm = toPlayer.normalize();
        double dot = look.dotProduct(toPlayerNorm);

        if (dot > bestDot) {
            bestDot = dot;
            best = player;
        }
    }
    return best;
}

Здесь мы используем скалярное произведение векторов (dotProduct). Если оно близко к 1 — значит направление взгляда и направление на игрока почти совпадают. Порог 0.97 даёт угол примерно 14 градусов — довольно точное прицеливание.

Можно двигать порог. Хочешь более точное наведение — ставь 0.99. Хочешь ловить цель даже при неточном прицеле — 0.95. Экспериментируй.

Что дальше

У тебя есть рабочий TargetHUD. Что можно добавить:

  • Отображение предмета во второй руке — через context.drawItem()
  • Иконки брони — у каждой части своя текстура
  • Цвет полоски HP — зелёный при полном, красный при низком
  • Анимация появления — панель плавно выезжает
  • Настройки в меню мода — через ModMenu и Cloth Config

Всё это — уже доработки, основа у тебя есть. Если что-то не заработало — смотри лог, там Mixin пишет причину.
